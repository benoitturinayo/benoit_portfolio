## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You need to have Node.js and npm (or yarn/pnpm) installed on your machine.

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/your_username/benoit_portfolio.git
   ```
2. Navigate to the project directory
   ```sh
   cd benoit_portfolio
   ```
3. Install NPM packages
   ```sh
   npm install
   ```
4. Start the development server
   ```sh
   npm run dev
   ```

The application will be available at `http://localhost:5173`.

## Deployment

This project can be easily deployed to services like Vercel, Netlify, or GitHub Pages.

For Vercel/Netlify, connect your GitHub repository and follow their instructions. The build command is `npm run build` and the output directory is `dist`.
